# Using Good Ground — 1.7.1

Install or update Good Ground through the release channel provided with your copy. Keep the existing app installed when applying an update so its local records remain available.

## Before changing phones or removing the app

Open **More → Settings → Backup & restore** and export a backup. Keep that file somewhere you can access again. Removing the app or clearing its storage can remove local records.

To restore, choose the backup file from Backup & restore. The app validates the file and shows a summary before you confirm replacement of the current household records. Canceling leaves the current records untouched.

## First use

Create your dog profiles, or skip the optional single-dog profile details. The tutorial is optional and can be replayed from **More → How to use Good Ground**. Use Lessons to browse skills; reading a lesson does not record progress.

Test the marker quietly away from your dog before training. Markers should be followed promptly by a suitable reward. Record progress only from the exact step's observed criterion and your dog's comfort.

Training works offline. Optional feedback requires an internet connection and sends only what you choose to submit. Records stay local unless you export them.

## Updates and support

Version 1.7.1 keeps curriculum 8, all existing dog records and backup format 3. Older supported backup formats remain importable. For a problem, note your device model, operating-system version, app version and the exact message. Export a backup before troubleshooting that could remove app data.

Build instructions and signing details belong in [DEVELOPING.md](DEVELOPING.md). Local build artifacts do not establish publication through an app store.
