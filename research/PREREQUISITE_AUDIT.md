# Full prerequisite audit — curriculum 8

Reviewed 154 current skills, 386 active teaching steps and 45 preserved earlier steps against versions 1.1.0, 1.1.1, 1.2.0 and 1.3.0. Active dependencies resolve and are acyclic. Every historical step has an active or preserved earlier page. No undocumented historical edge change is allowed by the audit script.

## Every current skill

| Skill | Required component edges across its steps | Review |
| --- | --- | --- |
| NAME · Name recognition | No external gate | Attention to a name is taught before distraction; a name is not assumed to be a recall or evidence of emotional comfort. |
| MARK · Reward marker | No external gate | Pair the chosen gentle signal with prompt reward; markers are optional and no later action is required after a terminal marker. |
| TOUCH · Hand target | No external gate | Voluntary empty-hand nose targeting transfers only after the basic contact; do not push a hand into the face. |
| SIT · Sit | No external gate | Comfortable voluntary sitting and early lure fading are appropriate; sitting is not mandatory for safety or proof of calm. |
| DOWN · Lie down | No external gate | Reward comfortable voluntary lowering without restraint; posture is distinct from relaxation. |
| STAND · Stand | No external gate | A comfortable stationary stand is useful independently of a down; avoid repeatedly luring the dog to walk forward. |
| FREE · Release from a position | No external gate | A release can be taught from any comfortable position; a completed sit is an unnecessary prerequisite. |
| DROP · Drop an item | No external gate | Trade willingly without chasing or prying; prevention and guarding assessment are distinct from a generic exchange exercise. |
| LEAVE · Leave an item alone | No external gate | Retain the cue, separately reinforce offered disengagement, teach modest context transfer, and keep hazards inaccessible without supervision. |
| WAIT · Short wait at an indoor doorway | FREE-2 (nearly there) | A short safe interior-door pause can be offered or cued; release and physical exit security remain explicit. |
